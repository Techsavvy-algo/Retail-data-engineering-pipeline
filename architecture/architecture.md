# Retail Data Engineering Pipeline

## Project Overview

A data engineering pipeline that processes retail
data using Databricks, PySpark and Delta Lake.

## Architecture

Source → Bronze → Silver → Gold → Analytics

## Technologies

- Python
- SQL
- PySpark
- Databricks
- Delta Lake
- Git
- GitHub

## Bronze Layer

Stores raw ingested data in Delta format.

## Silver Layer

Performs data cleaning, standardization,
null handling and duplicate removal.

## Gold Layer

Creates business-ready aggregated datasets.

## Data Quality

Includes null, duplicate, negative-value
and record-count validations.

## Business Analysis

Includes outlet, item and outlet-type
sales analysis.
